## Ground rules for this milestone

Estimate the cost of the run from real token counts measured on a pilot, and show me the estimate. Use the Message Batches API for J1, J4 and the J8 text, as `docs/ai-jobs.md` says.

## Step 1: shared foundations

1. **A small batch client** in `scripts/lib/`: submit a batch, poll it, fetch the results, and re-queue failed items. Keep it to what these jobs need.
2. **zod schemas** for every file this milestone produces:
   - the full `catalog.json` record with the J1 fields (spec Section 3.2, fixed vocabularies in Gap G1)
   - `copy.json` (9 lines per work, keyed by bucket)
   - `signals-seed.json` and `signals.json`
   - `j2-cache.json` and `j2-wordmap.json`

   Every file is validated at build time, and a bad file fails the build.
3. **The J2 prompt and output schema** live in one shared module under `src/lib/`. That module is used now by the pre-warm script and later by the M5 runtime route. One prompt, one place, so the cached answers and the live answers can never drift apart.

## Step 4: J4 curator lines

2. Build a validator that rejects:

   Re-queue whatever it rejects.
3. **Pilot** on the same 24 works, then estimate the full cost. **Stop for my approval.**

## Step 5: J8 seeded Signals data and findings

1. **Seed script:** fixed seed 20261008, 20,000 simulated sessions, real catalog IDs, segmented by the 3 by 3 mood buckets. Conversion means a simulated add-to-bag rate. Write it to `data/signals-seed.json`.
   - Give the simulation realistic structure so the findings mean something.
   - Write every structural assumption into the script's header comment, in plain language.
2. **Compute the four findings** into `data/signals.json` (spec Section 3.11, Gap G27):
   - a retail rack candidate
   - a frame or size attach pattern
   - an under-converting mood segment
   - a licensing gap (the bucket with the fewest catalog works per expected session)

   Each finding names a business action. Lift is the segment pick rate divided by the catalog-average pick rate.
3. **Finding text:** Claude writes each finding's sentence at build time from the computed figures.
   - A validator confirms every number in each sentence appears in the computed figures.
   - It also enforces the bans: no names, no "60-slot rack", no licensing-contract or data-rights language, no em dashes.
4. Show me the four findings with the figures behind each one. **Stop for my review.**
